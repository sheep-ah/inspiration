# 灵感（Inspiration）使用说明

一个**本地运行**的合同生成工具：导入 DOCX 模板，填写基础字段，一键生成合同文件。

> 合同内容、模板文件与填写的信息**全部在你自己的电脑上处理**，不会上传到任何服务器。
> 除「检查更新」与下载更新包外，应用不会发起网络请求。

## 1. 支持平台与下载

| 平台 | 安装包 | 说明 |
|---|---|---|
| Windows 10/11 64 位 | `inspiration_<版本>_windows_amd64_setup.exe` | 安装版（推荐，会顺带处理 WebView2 运行时） |
| Windows（免安装） | `inspiration_<版本>_windows_amd64_portable.exe` | 便携版，双击即用 |
| macOS Apple Silicon（M 系列） | `inspiration_<版本>_darwin_arm64.dmg` | 打开后把「灵感」拖进「应用程序」 |
| macOS Intel | `inspiration_<版本>_darwin_amd64.dmg` | 同上 |

下载地址：<https://github.com/sheep-ah/inspiration/releases>（每个版本还有 `.zip` 包，供应用内自动更新使用）

### macOS 安装步骤（重要）

1. 双击 `.dmg`，系统会挂载出一个窗口，里面有两个图标：**灵感** 和 **Applications（应用程序）**
2. 把 **灵感** 拖到 **Applications** 上 → 应用被复制进 `/Applications`，这一步才叫"安装"
3. 在 Finder 侧边栏点「推出」卸载这个 dmg 卷（或直接拖到废纸篓）
4. 从「应用程序」里启动「灵感」

> **不要直接在 dmg 窗口里双击「灵感」运行**：那只是从只读的 dmg 卷里临时运行，不会安装到电脑上，
> 而且只读卷无法被应用内更新替换，更新会失败。请务必先拖进「应用程序」。
>
> 若你的 dmg 是 v0.1.0 及更早版本（窗口里**没有** Applications 图标）：请打开一个 Finder 窗口进入
> 「应用程序」，再把 dmg 里的「灵感」拖过去；或改用 `.zip` 包解压后拖入。

### 首次打开被系统拦截怎么办

当前版本**未做代码签名**，系统会提示"未验证的开发者"：

- **macOS**：在「应用程序」里**右键**应用图标 → 「打开」→ 再点「打开」；或终端执行
  `xattr -dr com.apple.quarantine "/Applications/灵感.app"`
- **Windows**：SmartScreen 提示时点「更多信息」→「仍要运行」

## 2. 快速上手（三步）

1. **模板管理 → 上传模板**：选择你的合同模板（支持 `.docx`，也支持旧版 `.doc`）
2. **合同生成 → 选择模板 → 填写 11 个字段** → 点「生成合同」
3. 生成成功后点「打开文件」查看，或「打开所在文件夹」

## 3. 模板准备

### 3.1 占位符写法

在模板中需要填值的位置写 `{{字段名}}`，例如：

```
甲方（联系人）：{{联系人姓名}}
法定代表人：{{法人代表}}
联系电话：{{联系人电话}}
```

- 同一个字段可以出现多次，生成时会全部替换
- 字段名必须与下表**完全一致**（中文字符、无空格）
- 支持的占位符可以出现在：正文、表格、页眉、页脚、脚注、文本框、内容控件内
- 即使 Word 把 `{{联系人姓名}}` 拆成好几段显示，也能正确替换（无需手工处理）

### 3.2 支持的字段（11 个，全部必填）

| 占位符 | 说明 | 示例 |
|---|---|---|
| `{{联系人姓名}}` | 联系人姓名 | 张三 |
| `{{法人代表}}` | 法人代表 | 李四 |
| `{{实际经营地址}}` | 实际经营地址 | 北京市海淀区中关村大街1号院3号楼5层501室 |
| `{{联系人邮箱}}` | 联系人邮箱（会校验格式） | zhangsan@example.com |
| `{{营业执照名称}}` | 营业执照上的公司全称 | 示例科技（北京）有限公司 |
| `{{纳税人识别号}}` | 纳税人识别号（按文本处理） | 91110108MA01ABCD2X |
| `{{电话}}` | 固定电话 | 010-88886666 |
| `{{联系人电话}}` | 联系人手机号（与上行**分别录入**） | 13800000000 |
| `{{开户银行}}` | 开户银行（含支行全称） | 中国工商银行股份有限公司北京中关村支行 |
| `{{账户号}}` | 银行账号（**按文本处理，前导零会保留**） | 0001234567890123456 |
| `{{开票地址}}` | 开票地址 | 上海市浦东新区世纪大道100号A座20层 |

> 电话、账户号、纳税人识别号都按文本处理，不会因为数值转换丢掉前导零。

### 3.3 模板校验

上传后应用会立刻检查并给出结论：

| 提示 | 含义 | 处理 |
|---|---|---|
| 模板校验通过 | 可用于生成 | — |
| 存在不支持的占位符 `{{xxx}}` | 模板里的字段名不在支持列表中 | 按提示列出的字段名修改模板后重新上传 |
| 存在未闭合的占位符 | 只有 `{{` 没有 `}}`（常见于把占位符拆到了两个段落） | 在 Word 中把占位符补完整 |
| 占位符被换行/制表符打断 | 占位符中间被插入了换行、Tab、图形或域 | 删除中间的换行/元素，让占位符连成一段 |
| 未识别到任何占位符 | 模板里没有 `{{字段名}}` | 按 §3.1 添加占位符 |

**任何一项校验不通过时，应用会阻止生成**，避免生成缺少信息的合同。

### 3.4 只有 .doc 模板怎么办

**直接上传 `.doc` 即可**：应用会用本机已安装的 Word / WPS / LibreOffice 把它自动转换成 `.docx` 再导入，**原始 `.doc` 会一并保留**在数据目录里备查。

注意事项：
- 转换后请在 Word 中打开转换的结果核对版式（文本框、图文框位置可能与原稿不同）
- 若模板里还没有占位符，导入后会提示；按 §3.1 添加后重新上传
- 更稳妥的做法：在 Word 里「另存为 → Word 文档 (*.docx)」，再上传

## 4. 生成合同

- **保存位置**：默认在数据目录的 `contracts` 子目录，可点「更改位置」自选（建议选你的常用目录）
- **文件名**：留空则自动命名为 `合同-<公司名>-<日期>.docx`；也可以自己填
- **重名不覆盖**：若目标文件已存在，会自动生成 `… (2).docx`、`… (3).docx`，绝不静默覆盖
- **原模板不会被修改**：生成只写新文件
- **失败不丢数据**：生成失败时表单内容保留，可修正后重试

### 输出格式：DOCX 还是 DOC

| 格式 | 什么时候用 | 说明 |
|---|---|---|
| **DOCX**（默认） | 一般情况 | 版式保真最好 |
| **DOC**（Word 97-2003） | 下游系统要求必须 `.doc` | 应用会用本机 Word/WPS/LibreOffice 转换；**默认同时保留一份 `.docx` 备份**，可用于打印/存档 |

关于 `.doc` 的已知差异：
- 用 **Microsoft Word / WPS** 转换时版式与原稿基本一致（应用会优先选它们）
- 只有 **LibreOffice** 可用时：表格宽度会被写成 100% 内容宽度、页面可能有少量重排（文字不会丢失）
- 想完全一致：用 DOCX，或在 Word 里手工「另存为 Word 97-2003」
- 查看当前可用转换通道：命令行执行 `灵感 --check-converters`

## 5. 数据存在哪里 / 怎么备份

| 平台 | 数据目录 |
|---|---|
| macOS | `~/Library/Application Support/灵感/` |
| Windows | `%APPDATA%\灵感\`（即 `C:\Users\<你>\AppData\Roaming\灵感\`） |

目录内容：

```
灵感/
├── inspiration.db     数据库（模板信息、生成记录）
├── templates/         模板文件副本（含从 .doc 转换时保留的原件）
├── contracts/         默认的合同输出目录
├── logs/              本地日志（不含合同字段值）
└── update/            更新包下载临时目录
```

- 应用内有「关于 → 打开数据目录」按钮
- **备份**：直接复制整个目录即可
- **升级/重装应用不会清空数据**；卸载时若需一并删除数据，请手动删除该目录
- 换电脑迁移：把整个目录复制到新电脑的同一位置

## 6. 应用内更新

「关于」页 →「检查更新」：

- 有新版本会显示版本号、发布时间与更新说明
- 点「下载并更新」：显示下载进度 → 自动校验文件完整性（SHA256）→ 安装 → 应用自动重启
- **更新不会动你的模板与合同数据**；macOS 上会保留一份旧版本备份（`.backup-<时间戳>`，7 天后自动清理）
- 更新失败不会影响当前可用版本，可重试；也可以点「前往发布页」手动下载
- 可勾选「启动时自动检查更新」（默认关闭）

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示"模板中存在不支持的占位符" | 模板里的字段名与支持的 11 个不一致；按提示列出的字段名修改 |
| 提示"模板文件已丢失" | 模板文件被移动/删除；到「模板管理」删除该模板后重新上传 |
| 提示"保存位置不可写" | 换一个目录（如桌面或文档），或检查该目录权限 |
| 生成 `.doc` 失败并提示需要转换器 | 本机没有 Word/WPS/LibreOffice；安装任意一个即可，或改用 DOCX |
| 账户号前导零丢失 | 不会发生（全程按文本处理）；若模板里用了数值型域，请改为文本 |
| 打开应用"没反应" | 应用会在启动失败时弹窗说明原因（如数据文件损坏）；也可查看 `logs/` 下的日志 |
| 应用内检查更新失败 | 检查网络（需要访问 github.com）；也可直接到发布页手动下载 |
| 更新后想回退 | macOS：数据目录同级的 `灵感.app.backup-<时间戳>` 就是旧版本，替换回去即可（备份保留 7 天） |

## 8. 已知限制

1. **模板中的占位符不能跨段落**：`{{` 与 `}}` 必须在同一段（Word 里如果敲了回车就会跨段，会被校验拦下）
2. **占位符中间不能有换行、Tab、图形或域代码**：会被校验拦下并提示
3. **只支持 `.docx` / `.doc` 模板**，不支持 `.docm`（宏）、PDF 模板、加密文档
4. **图表数据、SmartArt、艺术字里的文字不是 `w:t`**，不参与替换（普通文本框、页眉页脚、脚注、内容控件都支持）
5. **`.doc` 输出的版式差异**（见 §4）：LibreOffice 通道会改表格宽度
6. **未做代码签名/公证**：首次打开需要手动放行（见 §1）
7. 第一版**不提供**：PDF 导出、账号登录、云端同步、多人协作、在线签署、电子印章、审批流
