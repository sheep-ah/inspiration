# 风险清单与未验证项（阶段 1 交付物）

> 任务书 §6.5 要求逐项记录“通过 / 失败 / 未验证”。本文件是唯一的“未验证”清单来源，后续阶段每完成一项就更新本文件。

## 1. 主要风险

| # | 风险 | 影响 | 概率 | 应对 | 状态 |
|---|---|---|---|---|---|
| R1 | 未签名/未公证的安装包触发 macOS Gatekeeper、Windows SmartScreen 警告 | 用户无法直接双击运行，更新流程受限 | 高（无证书时必然） | 申请 Apple Developer ID + Windows 代码签名证书；无证书时在用户文档中给出“右键打开 / 解除隔离”说明，并在界面提示 | **待用户决策**（见 §3） |
| R2 | 用户模板中的占位符被换行/制表符/域代码打断 | 该模板无法生成（已阻止，不会产生缺信息合同） | 中 | 校验阶段阻止 + 明确提示；文档给出修复方法；后续可考虑“自动修复”独立需求 | 已缓解 |
| R3 | 用户模板使用非 `w:t` 承载文本（图表 `a:t`、SmartArt、艺术字） | 占位符不被替换 | 低 | 导入时提示“未识别到占位符”的部件类型；文档列出支持范围 | 已缓解 |
| R4 | 复杂模板（文本框、内容控件、嵌套表）在真实 Word 中的渲染差异 | 生成结果与预期不符 | 中 | 阶段 3 用真实 Word 文件回归；已建立可扩展的语料库与独立校验脚本 | 部分验证（LibreOffice 已通过，Word 未验证） |
| R5 | 中文长文本在 WebView 中的输入/换行体验 | 表单体验差 | 低 | Wails 使用系统原生输入控件；阶段 3 专项测试 | 未验证（需真机） |
| R6 | macOS 整包替换更新在 `~/Applications` 或 `/Applications` 权限不足时失败 | 更新不成功 | 中 | 失败时回退为“打开 dmg 引导手动安装”，并保留旧版本可用 | 方案已定，未验证 |
| R7 | Windows 下 NSIS 静默安装 + 自动重启的行为差异（UAC、安装目录、杀软拦截） | 更新失败或残留旧进程 | 中 | 默认 user scope 免 UAC；阶段 5 在真机验证；失败回退为打开安装器让用户点“下一步” | 未验证 |
| R8 | GitHub 仓库权限/Secrets 缺失导致 CI 与发布不可用 | 阶段 4/5 阻塞 | 中 | 阶段 1 结束时确认仓库与凭据（见 §3） | **待用户输入** |
| R9 | 第三方面板依赖的许可证与安全风险 | 合规风险 | 低 | 依赖清单已冻结并核对许可（MIT/BSD），CI 加 `govulncheck` | 已缓解 |
| R9 | 第三方依赖的许可证与安全风险 | 合规风险 | 低 | 依赖清单已冻结并核对许可（MIT/BSD），CI 加 `govulncheck` | 已缓解 |
| R11 | 应用数据目录被误删（用户清理工具） | 模板丢失 | 低 | 文档给出备份路径；模板导入时校验文件存在并在列表中标记缺失 | 方案已定 |
| R12 | 大模板（数十 MB、含大量图片）导致解析/生成耗时 | 界面卡顿 | 低 | 解析在后台 goroutine 执行 + 进度事件；设置单文件大小上限；耗时实测留到阶段 3 | 未验证 |
